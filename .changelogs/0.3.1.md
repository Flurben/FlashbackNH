Fixes for GregTech hatches and AE2 cables in replays.

FlashbackNH is an unofficial, independent reimplementation of the feature set of Flashback. It is not affiliated with or endorsed by Flashback or its author.

## Fixes

- **GregTech hatches with missing textures.** Hatches and buses that were already in the world when a recording started mid-session showed as purple and black blocks in the replay. The recording only kept a hatch's texture, not the machine itself. Recordings now keep the whole machine.
- **Disconnected AE2 cables.** ME cables in the same situation showed as separate stubs instead of connected lines. Applied Energistics works out cable connections on the server, so the client could not describe them. The client now keeps the cable data the server last sent and the recording uses that. This works in singleplayer and on servers.

Both fixes apply to new recordings. Replays recorded with earlier versions do not have the missing data, so they still show these problems.

## Install

Put `flashbacknh-0.3.1.jar` in your `mods` folder. It is client only. Do not use the `-dev` or `-sources` jars.

## Known limits

- Tested in singleplayer with an input hatch and fluix cables. The cable fix uses the same code on a server, but that was not tested.
- Starting a recording mid-session can take a little longer, as more tile entity data is saved (about 50 ms more in a test world).
- Everything listed for 0.3.0 still applies.

See the README for the full list of tested versions and limitations.
