Rewinding a replay is much faster.

FlashbackNH is an unofficial, independent reimplementation of the feature set of Flashback. It is not affiliated with or endorsed by Flashback or its author.

## Changes

- Going back to an earlier point in a replay keeps the world and restores only what differs, instead of loading everything again from the start. At 32 chunks render distance a rewind freezes for about 0.25 to 0.7 s, down from 1.3 to 5.2 s, and the terrain no longer disappears while it is rebuilt.
- Going back past a pause or dimension change in the recording still reloads the world, which is slower (about 1.4 to 2.3 s in the same test).
- Sounds and particles of the ticks a seek skips over are no longer played. Jukebox music still is.
- Video exports still load the world from scratch, so they do not depend on this.

## Install

Put `flashbacknh-0.1.1.jar` in your `mods` folder. It is client only. Do not use the `-dev` or `-sources` jars. Replays recorded with 0.1.0 still open.

## Known limits

- How long a rewind takes still grows with the distance to the last world snapshot in the recording. Long recordings, large bases, multiplayer and shaders have not been tested with this change.
- Everything listed for 0.1.0 still applies, including the short freeze when a recording starts mid-session.
- A game freeze was seen once during recording with Distant Horizons and Et Futurum, in Et Futurum's chunk loading and without FlashbackNH code involved. It could also happen without this mod.

See the README for the full list of tested versions and limitations.
